Entry for [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) — one coined English word with a one-line definition.

> miswave — waving back at a stranger who was waving at the person behind you, then pretending you meant it.

## Run

```sh
python3 main.py
```

Writes the line to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output`). Stdlib only, no network, deterministic.
